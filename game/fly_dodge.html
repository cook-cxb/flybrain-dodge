What comes from the connectome and what I assumed

From the data: which cell types connect to which (synapse counts between cell type and body side), whether each type is likely excitatory or inhibitory (predicted neurotransmitter), and how strongly each descending neuron is driven by the left or right eye. Nothing about those connections is invented here.

My modelling choices:

  • Each obstacle becomes a looming signal: how fast it grows on the fly's retina, counted only if it is on course to hit. Every detector type (LPLC2, LC4, LC6, LPLC1) gets the same signal for its own eye. The data doesn't tell me how each type differs in tuning.
  • Each cell type and side is one unit with a firing rate between 0 and 1. Inputs are weighted by synapses per receiving neuron, then squashed. Thresholds are set automatically from the loaded file.
  • Activity in left-side descending neurons pushes the fly right, and the reverse. When both sides fire equally the fly backs away (down) instead. This is one rule for all descending neurons; I did not assign roles to individual ones.
  • The fly goes up only through a weak drift back to its home spot. The tables have no information about where in the visual field a neuron looks, so up and down cannot be read from the wiring.
  • Sign: acetylcholine counts as excitatory, GABA and glutamate as inhibitory (glutamate can be either in flies). Unknown transmitters have no effect.

The two controls in the Brain panel test whether the wiring matters. Rewiring keeps every connection strength but sends each one to a random target cell type, so left/right structure is lost.
